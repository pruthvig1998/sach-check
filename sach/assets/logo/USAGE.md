# Sach logo: usage

**The mark:** WhatsApp's forward arrow inside Sach's verdict stamp, tilted 8 degrees like the verdict stamps on the site. Every forward gets a verdict.

## Files
| Use | File |
|---|---|
| Main logo (website header, documents) | `lockup-horizontal.svg` |
| Stacked (square spaces, posters) | `lockup-stacked.svg` |
| Symbol alone | `symbol-red.svg` (colour), `symbol-black.svg`, `symbol-ink.svg`, `symbol-paper.svg` |
| On dark backgrounds | `lockup-horizontal-reversed.svg`, `symbol-paper.svg` |
| One colour (print, stamps, embroidery) | `lockup-horizontal-black.svg`, `symbol-black.svg` |
| App icon | `symbol-tile.svg`, `icon-192.png`, `icon-512.png`, `maskable-512.png`, `apple-touch-icon.png` |
| Favicon (built from the heavier small-size cut `symbol-small.svg`) | `favicon.ico`, `favicon.svg`, `favicon-16/32/48.png` |
| Website `<head>` | `head-snippet.html`, `site.webmanifest` |

Same three colours as sachcheck.in. Stamp red on paper and ink on paper both pass WCAG AA for large graphics.

## Rules
- **Clear space:** keep a gap equal to the stamp's border width times two on every side (about 15% of the symbol's height).
- **Minimum size:** symbol 24 px on screen (use `symbol-small.svg` from 16 to 48 px); horizontal lockup 96 px wide; 20 mm in print.
- **Keep the tilt.** The 8-degree tilt is part of the mark. Never straighten, re-rotate or flip it (the arrow must point right).
- **Do not** recolour outside the three colours, add shadows or outlines, stretch it, put the symbol on busy photos, or redraw the arrow from another icon set.
- **Wordmark:** "Sach" in Fraunces Black (weight 900, optical size 72), outlined, tracked -0.02 em. Licence: SIL Open Font License (`FRAUNCES-OFL.txt`), free for logos.
